Account / Business related events
1) account_alerts

काय: अकाउंट संबंधित “alerts/warnings” (उदा. policy, quality, messaging limits, payment issues, इ.)
use:

Admin ला warning/notification पाठवणे

Risk कमी करण्यासाठी action (template/number change, messaging throttle)

2) account_review_update

काय: अकाउंट review ची स्थिती बदलली (pending/approved/rejected वगैरे).
use:

Onboarding flow automate करणे

Rejected झाल्यास reason track करून compliance fix करणे

3) account_update

काय: अकाउंट सेटिंग/प्रोफाइल/कॉन्फिगमध्ये बदल.
use:

तुमच्या CRM/DB मध्ये business account info sync ठेवणे

Config बदलला की integration adjust करणे

4) business_capability_update

काय: अकाउंट/बिझनेस capabilities बदलल्या (उदा. messaging tier/limit, काही features enable/disable).
use:

Sending rules adjust (rate limit, daily cap)

UI मध्ये “काय available आहे” ते दाखवणे

5) history

काय: इतिहास/रिकव्हरी/री-प्ले प्रकारचे events (कधी कधी missed events भरून काढण्यासाठी).
use:

Downtime नंतर backlog reconcile

Audit/logging पूर्ण ठेवणे

Message Template related events
6) message_template_components

काय: template च्या components मध्ये बदल/डिटेल अपडेट (header/body/buttons/variables).
use:

Template-builder UI sync

चुकीचे variables/format लवकर detect करणे

7) message_template_quality_update

काय: template ची quality rating बदलली (quality down/up).
use:

Deliverability सुधारण्यासाठी template rewrite

Low-quality template वापरणं थांबवून account protect करणे

8) message_template_status_update

काय: template status बदलला (submitted/approved/rejected/paused/disabled).
use:

Approved झाल्यावर campaign/automation सुरू करणे

Rejected reason वरून correction workflow

9) template_category_update

काय: template category बदलली/अपडेट झाली (उदा. marketing/utility/authentication).
use:

Pricing/eligibility logic (कधी कोणते templates पाठवता येतात)

Compliance आणि reporting

“messages” (यात सगळ्यात जास्त काम असतं)
messages → Overview

काय: messages webhook payload ची बेस रचना आणि common fields.
use:

तुमचा parser/handler योग्य प्रकारे build करणे

एकाच endpoint वर वेगवेगळे message types handle करणे

Incoming message types (user → तुम्ही)
10) text messages

काय: normal text.
use: chatbot/agent routing, NLP, intent detection.

11) audio messages

काय: voice note/audio file (media id येतो).
use: audio download → transcription → ticket/summary/agent handoff.

12) image messages

काय: फोटो/इमेज.
use: media download, OCR/analysis, support proofs (bill, screenshot).

13) video messages

काय: video.
use: verification, support evidence, moderation/processing.

14) document messages

काय: PDF/Doc/other files.
use: KYC docs, resumes, invoices, storage + workflow.

15) sticker messages

काय: sticker.
use: engagement analytics / sentiment संकेत (कधी media म्हणून treat).

16) location messages

काय: user ने location share केली.
use: delivery/field-service, nearest branch, visit planning.

17) contacts messages

काय: contact card share.
use: lead capture, referral flows, address book sync.

18) button messages

काय: user ने quick reply/button click केला.
use: guided conversation, form-like choices, error कमी.

19) interactive messages

काय: lists, reply buttons, structured interactions (कधी flows).
use: menus, selection-based journeys, “tap-to-choose” UX.

20) order messages

काय: catalog/commerce order related message.
use: order processing, inventory, invoice, fulfillment automation.

21) group messages

काय: group मध्ये message (जर तुमच्या setup मध्ये supported असेल).
use: community moderation bots, announcements, group support.

22) unsupported messages

काय: असा message type जो तुम्ही process करू शकत नाही.
use: fallback reply (“हा प्रकार सध्या supported नाही; कृपया text मध्ये पाठवा”), analytics.

23) system messages

काय: system-generated updates (काही account/device/security प्रकार).
use: housekeeping, audit trails, user experience continuity.

Message lifecycle / feedback events
24) status messages

काय: तुम्ही पाठवलेल्या message ची स्थिती: sent/delivered/read/failed.
use:

Delivery dashboard

Retry logic (failed)

SLA tracking

25) errors messages

काय: processing/delivery errors (उदा. media fetch fail, policy issue).
use:

Alerts + auto-retry

Root-cause logs

26) reaction messages

काय: user ने तुमच्या message ला reaction दिला (emoji).
use: feedback/CSAT संकेत, lightweight analytics.

Phone number / payment / security / SMB related events
27) phone_number_name_update

काय: phone number display name मध्ये बदल.
use: brand consistency, compliance checks, UI sync.

28) phone_number_quality_update

काय: number quality rating बदलली.
use: messaging volume throttle, template सुधारणा, number protect.

29) payment_configuration_update

काय: payment/billing configuration बदलली.
use: billing readiness, paid messaging सुरु/थांबवणे, finance alerts.

30) security

काय: security-related event (access/token/permission anomalies वगैरे).
use: incident response, key rotation, access revoke.

31) user_preferences

काय: user preferences/opt-in/opt-out प्रकारचे updates (विशेषतः marketing consent).
use: compliance (Do-not-disturb), segmentation, safe outreach.

32) partner_solutions

काय: partner/BSP solutions संबंधी updates.
use: embedded signup, partner configs, managed accounts workflow.

33) smb_app_state_sync

काय: SMB (small business) app state sync संबंधित update.
use: business app + backend मध्ये state consistency.

34) smb_message_echoes

काय: SMB app मधून send झालेले messages “echo” म्हणून तुमच्या webhook ला येतात (logging/sync साठी).
use: एकाच timeline मध्ये inbound + outbound track, CRM sync.
